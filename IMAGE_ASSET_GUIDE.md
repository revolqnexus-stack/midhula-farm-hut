# IMAGE ASSET GUIDE — MIDHULA FARM HUT

## Image Production Philosophy

**CRITICAL:** We generate images in the order the website needs them, maintaining visual continuity across all assets.

All images must feel like they belong to the same visual campaign:
- Consistent lighting and colour grading
- Similar camera style and composition
- Photorealistic quality
- Accurate fish anatomy
- Editorial art direction

## Mobile Considerations

For each desktop image, consider:
- Will the composition work when cropped to mobile aspect ratios?
- Is the subject still clearly visible?
- Does important detail remain in frame?
- Should we generate a dedicated mobile variant?

**Hero images:** Generate both desktop (16:9) and mobile (9:16) versions

**Species cutouts:** Square format works well across all devices

**Farm photography:** Test crops carefully; may need mobile-specific versions

---

## Implementation Guidelines

1. **Use Shopify-hosted assets** through theme settings or asset pipeline
2. **Never hardcode external image URLs**
3. **Provide fallback colors** that load before images
4. **Implement proper lazy loading** for below-fold content
5. **Use srcset and sizes** for responsive images
6. **Include descriptive alt text** for accessibility
7. **Maintain aspect ratio containers** to prevent layout shift
8. **Test loading performance** on 3G networks
