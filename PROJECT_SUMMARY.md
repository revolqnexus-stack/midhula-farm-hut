## Design System Highlights

### Colors

```css
Aquatic Blue:    #7BC8D9  /* Primary brand */
Deep Teal:       #174D59  /* Contrast */
Leaf Green:      #7CA66A  /* Nature */
Coral Orange:    #F16B4E  /* CTA accent */
Paper:           #F7F2E8  /* Background */
Ink:             #243A35  /* Text */
```

### Typography Scale

- Hero headlines: 60-96px
- Section headings: 48px
- Body text: 16-20px
- Mobile optimized scales

### Spacing System

4px baseline grid with logical scale:
4px → 8px → 16px → 24px → 32px → 64px → 128px

### Animation Principles

- Float: Gentle up/down movement
- Drift: Horizontal swimming motion
- Fade-in-up: Section reveals
- Organic easing: `cubic-bezier(0.33, 1, 0.68, 1)`

## How to Deploy (Quick Version)

1. **Generate images** using prompts in `IMAGE_ASSET_GUIDE.md`
2. **Create Shopify dev store** (free)
3. **Run:** `shopify theme dev --store=your-store.myshopify.com`
4. **Upload images** via theme customizer
5. **Create 3-5 collections** with sample products
6. **Test** on mobile and desktop
7. **Submit** the live URL
